Antes de empezar

Buscando el servidor...
1. Aquí no se escribe códigoSe elige, se marca, se arma con botones y se piensa. Todo se hace con toques o clics.
2. Las estrellas se pierdenCada misión vale 3. Puedes fallar una vez o pedir una pista sin perder nada; de ahí en adelante cada una resta. Piénsalo antes de apretar «Comprobar».
3. Se entrega un códigoAl final recibes un código de 8 caracteres y un PDF. El código es lo que vale.
