Los tiempos por misión se muestran en mm:ss. Si un mismo estudiante aparece más de una vez, se marca como "Repetido": revisa cuál entregó. El registro se guarda solo en este navegador; descarga una copia JSON o el CSV para no perderlo.

Cómo leer el estado

Válido el código es auténtico y la nota coincide con las estrellas. Alterado el código fue modificado, está incompleto o no fue generado por el laboratorio. Repetido hay más de un código para el mismo estudiante y grupo. Incompleto el código es válido pero faltan misiones.

Límite honesto: la clave de verificación vive en el código del laboratorio, que es una página pública; un estudiante con conocimientos técnicos podría fabricar un código. Cambia la clave por una propia en ambos archivos antes de publicar, y contrasta el código con el PDF cuando algo te parezca raro.
